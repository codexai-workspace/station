# Induvara Sorting Station — Digital Twin 3D + GX Works3

โมเดล 3D ของสถานีคัดแยกชิ้นงาน 3 วัสดุ (เหลือง / ดำ / อะลูมิเนียม) พร้อมตู้คอนโทรล FX5U
ใช้ได้ 3 แบบ:

| แบบ | ใครคุมเครื่อง | ต้องมี |
|---|---|---|
| **จำลองในเว็บ** | ลำดับจำลองในตัวเว็บ | เบราว์เซอร์อย่างเดียว |
| **GX Simulator3** | โปรแกรม Ladder ของคุณใน GX Works3 (จำลอง) | GX Works3 + MX Component + Python ที่มี pywin32 + Node.js |
| **PLC จริง (LAN)** | FX5U จริง ผ่านสายแลน (SLMP) | Node.js + สายแลน |

```
เบราว์เซอร์ (3D) ⇄ HTTP/SSE ⇄ bridge/server.js ⇄ MX Component (COM) ⇄ GX Simulator3
                                               ⇄ SLMP 3E binary (TCP) ⇄ FX5U จริง
```

---

## 1. เปิดโปรแกรม

1. ติดตั้ง **Node.js LTS** (https://nodejs.org) ครั้งเดียว
2. ดับเบิลคลิก **`start.bat`** → เบราว์เซอร์จะเปิด `http://localhost:8000` ให้เอง
3. เปิดหน้าต่างดำ (server) ค้างไว้ตลอดการใช้งาน ปิดหน้าต่าง = ตัดการเชื่อมต่อ

> ถ้าเครื่องไม่มี Node.js, `start.bat` จะเปิดแบบจำลองในเว็บอย่างเดียว (ปุ่มเชื่อม PLC ใช้ไม่ได้)
> ถ้าขึ้นว่าพอร์ต 8000 ถูกใช้ ให้ปิดหน้าต่าง server เดิมก่อน

บนหน้าเว็บ กด **"เชื่อมต่อ GX Works3 / PLC"** ในแผงด้านขวา แล้วเลือกรูปแบบ

## 2. ต่อกับ GX Simulator3 (ไม่ต้องมี PLC จริง)

### ติดตั้งครั้งแรก
1. ติดตั้ง **MX Component** (v4 หรือ v5) จาก Mitsubishi
2. ติดตั้ง Python + pywin32
   - MX Component **v4** เป็น COM 32-bit → ต้องใช้ **Python 32-bit**
   - เปิด Command Prompt แล้วรัน `py -3.12-32 -m pip install pywin32` (หรือ `python -m pip install pywin32`)
3. ในหน้าเว็บ ช่อง **Python ที่มี pywin32** ใส่คำสั่งที่ใช้เรียก Python ตัวนั้น เช่น `python` หรือ `py -3.12-32`
   แล้วกด **ตรวจสอบ Python + MX Component** ต้องขึ้น ✓ ครบ 3 ข้อ

### ตั้ง Logical Station (ครั้งแรก)
1. เปิด **Communication Setup Utility** (ติดมากับ MX Component)
2. **Wizard** → Logical Station Number = `1` (หรือเลขอื่น)
3. PC side I/F = **GX Simulator3** → CPU Type = **FX5U** → Finish

### ทุกครั้งที่ใช้งาน
1. GX Works3 เปิดโปรเจกต์ FX5U ที่มีโปรแกรมคัดแยก (ดูตัวอย่างในข้อ 5)
2. **Debug → Simulation → Start Simulation** รอจน GX Simulator3 เขียนโปรแกรมเสร็จและเป็น **RUN**
3. หน้าเว็บ → เชื่อมต่อ PLC → **GX Simulator3** → Station No. = เลขในข้อ "ตั้ง Logical Station"
4. กด **ทดสอบ** → ต้องขึ้น `✓ ติดต่อได้ · SM400 = 1`
5. หน้าที่ของเว็บ = **จำลองเครื่องจักร** → กด **เชื่อมต่อ**
6. กด **▶ เริ่มทำงาน** (= กดปุ่ม X0) หรือคลิกปุ่ม MASTER ON บนตู้ 3D

> แก้ Ladder แล้วต้อง Start Simulation ใหม่ (หรือ Write to PLC ไปที่ Simulator) หน้าเว็บจะต่อใหม่ให้เองภายใน 2 วินาที
> MX Component อ่านค่าครั้งละ ~30 ms ตัว server จึงอ่าน Y ทุกรอบ และอ่าน X ห่างกว่า (เพราะเว็บเป็นคนเขียน X เอง)

## 3. ต่อกับ FX5U จริงด้วยสายแลน

### ตั้งค่าใน GX Works3 (ครั้งแรก)
1. Navigation → **Parameter → FX5UCPU → Module Parameter → Ethernet Port**
2. **Basic Settings → Own Node Settings**
   - IP Address: เช่น `192.168.3.250` (ค่าเริ่มต้นของ FX5U) · Subnet `255.255.255.0`
   - **Communication Data Code = Binary**
   - **Enable/Disable Online Change = Enable All (SLMP)** (ถ้าไม่เปิด จะเขียนค่าขณะ RUN ไม่ได้)
3. **External Device Configuration → Detailed Setting**
   - ลาก **SLMP Connection Module** จากรายการด้านขวามาวาง
   - Protocol = **TCP**, Port No. = เช่น `5007` (ถ้า GX Works3 แจ้งว่าใช้ไม่ได้ ให้เลือกเลขอื่นแล้วใส่เลขเดียวกันในหน้าเว็บ)
   - **Close with Reflecting the Setting** → Apply
4. **Convert All** → **Online → Write to PLC** (Parameter + Program)
5. **Reset PLC หรือปิด-เปิดไฟ** เพื่อให้ค่า Ethernet ใหม่มีผล

### ตั้งค่าคอมพิวเตอร์
- ตั้ง IP การ์ดแลนเป็นวงเดียวกับ PLC เช่น `192.168.3.10` / `255.255.255.0` (Gateway เว้นว่างได้)
- ต่อสายแลนตรงเข้า PLC หรือผ่าน Switch
- ทดสอบ: Command Prompt → `ping 192.168.3.250`

### ในหน้าเว็บ
1. เชื่อมต่อ PLC → **PLC จริง (LAN)** → ใส่ IP และ Port
2. กด **ทดสอบ** → `SM400 = 1` คือสำเร็จ (ถ้า SM400 = 0 แปลว่า CPU อยู่ STOP)
3. เลือกหน้าที่ของเว็บ
   - **Monitor อย่างเดียว** — ใช้กับเครื่องจริงที่ต่อสาย I/O ครบ เว็บอ่าน X/Y มาแสดงบน 3D ไม่เขียนอะไรเลย (ปลอดภัย)
   - **จำลองเครื่องจักร** — ใช้เมื่อ PLC ไม่ได้ต่อเครื่องจริง เว็บเขียน X และขยับ 3D ตาม Y
4. กด **เชื่อมต่อ**

> ⚠ **จำลองเครื่องจักรกับ PLC จริง**: Output ของ PLC จะออกจริง ถ้ามีมอเตอร์/วาล์วต่ออยู่ เครื่องจะขยับ ให้ตัดไฟ 24V ของ Output และตัดลมก่อน
>
> ⚠ **X ที่มีสายจริง** (X0–X17 บนตัว FX5U และ X100–X117 ที่ Refresh จาก CC-Link IE Field Basic) จะถูก PLC เขียนทับทุกสแกนด้วยค่าจากขั้วจริง
> ถ้าจะให้เว็บจำลองเซนเซอร์บน PLC จริง ให้เปลี่ยน Address ของ Input ในตาราง I/O เป็น **M** (เช่น M1000–M1017) แล้วให้ Ladder ใช้ M เหล่านั้นแทน X

## 4. ตาราง I/O (แก้ไขได้)

กดปุ่ม **ตาราง I/O** มุมซ้ายบน แก้ Address / Tag / คำอธิบายได้ทุกช่อง (บันทึกในเบราว์เซอร์อัตโนมัติ, ส่งออก CSV ได้)
คอลัมน์ไฟเขียว = ค่าจริงจาก PLC เมื่อเชื่อมต่อ

- X/Y ของ FX5 เป็น **เลขฐาน 8** (X7 → X10) · ใช้ M/L (ฐาน 10) หรือ B (ฐาน 16) แทนได้
- แต่ละแถวผูกกับสัญญาณของโมเดล 3D ไว้ เปลี่ยน Address ได้เลย สัญญาณจะตามไป

### ค่าเริ่มต้น

**PLC (FX5U-32MR/ES) — ตู้คอนโทรล**

| Address | Tag | ความหมาย | ทิศทาง |
|---|---|---|---|
| X1–X7 | PB_IN1–PB_IN7 | ปุ่ม INPUT 1–7 | เว็บ → PLC |
| X0, X10–X17 | — | สำรอง | — |
| — (ไม่ได้ต่อ) | PB_MASTER_ON | ปุ่ม MASTER ON = **START Auto** (ปุ่ม ▶ บนเว็บ) | — |
| — (ไม่ได้ต่อ) | PB_CONTROL_POWER | ปุ่ม CONTROL POWER | — |
| — (ไม่ได้ต่อ) | PB_IN0 | ปุ่ม INPUT 0 = **STOP** (ปุ่ม Ⅱ บนเว็บ) | — |
| — (ไม่ได้ต่อ) | ES_CABINET | Emergency stop ตู้ **NC** | — |
| Y0–Y5 | PL_OUT0–5 | ไฟ OUTPUT 0–5 บนตู้ | PLC → เว็บ |
| Y6 | PL_CONTROL_ON | ไฟ CONTROL ON | PLC → เว็บ |

**CC-Link IE Field Basic (NZ2MFB1-32DTE1) — สถานี** (เริ่ม X100 / Y120)

| Address | Tag | ความหมาย | ทิศทาง |
|---|---|---|---|
| X100 | SEN_PHOTO | Photoelectric (ติด: เหลือง, อะลูมิเนียม) | เว็บ → PLC |
| X101 | SEN_CAP | Capacitive (ติดทุกวัสดุ) | เว็บ → PLC |
| X102 | SEN_IND | Inductive (ติดเฉพาะโลหะ) | เว็บ → PLC |
| X103 / X104 | FEED_RET / FEED_EXT | กระบอกป้อน หดสุด / ยืดสุด | เว็บ → PLC |
| X105 / X106 | CYL_A_RET / CYL_A_EXT | กระบอกราง A หดสุด / ยืดสุด | เว็บ → PLC |
| X107 / X110 | CYL_B_RET / CYL_B_EXT | กระบอกราง B หดสุด / ยืดสุด | เว็บ → PLC |
| X111 | MAG_EMPTY | แมกกาซีนว่าง | เว็บ → PLC |
| X112 | ES_STATION | Emergency stop สถานี **NC** | เว็บ → PLC |
| Y120 | MOTOR_CONV | มอเตอร์สายพาน (RUN) | PLC → เว็บ |
| Y121 | SOL_FEED | วาล์วกระบอกป้อน (ค้าง = ยืด) | PLC → เว็บ |
| Y122 | SOL_A | วาล์วกระบอกราง A | PLC → เว็บ |
| Y123 | SOL_B | วาล์วกระบอกราง B | PLC → เว็บ |
| Y124 | MOTOR_REV | สายพานกลับทาง (วิ่งไปทางราง A) ใช้คู่กับ Y120 | PLC → เว็บ |

> ใน GX Works3 ตั้ง CC-Link IE Field Basic → Refresh Settings ให้ RX = X100, RY = Y120 (ตามเครื่องจริงของคุณ)
> ถ้าเครื่องจริงใช้เลขอื่น แก้ในตาราง I/O ให้ตรงได้เลย

### พฤติกรรมของเครื่องจำลอง (ใช้ตั้งเวลาใน Ladder)
- สายพานวิ่ง **1.75 หน่วย/วินาที** · ชิ้นงานถูกป้อนลงที่ตำแหน่ง 0 (ใต้ CAP)
- เซนเซอร์: PHOTO ที่ −0.85 · CAP ที่ 0 · IND ที่ +0.85 (ทิศ + = เดินหน้า)
- ราง A ที่ −2.10 (ต้องถอยหลัง) · ราง B ที่ +3.00 · ปลายสายพาน ±5.45 (ชิ้นงานตกออก)
- กระบอกป้อน: ยืด 0.9 s · กระบอก A/B: ยืด 0.42 s · Single solenoid (ดับ = หดกลับ)
- กระบอก A/B ดันชิ้นงานที่อยู่ห่างไม่เกิน ±0.5 จากแนวกระบอก · รางละ 3 ชิ้น (เต็มแล้วดันไม่เข้า)
- ชิ้นงานใหม่หล่นจากแมกกาซีนเมื่อกระบอกป้อนหดสุดเท่านั้น

## 5. ตัวอย่าง Ladder (FX5U) — คัดแยกด้วยเซนเซอร์ + Timer

ลำดับ: ป้อน → เดินหน้าไปที่ IND (จำว่าเป็นโลหะไหม) → โลหะ: ไปราง B แล้วดัน
→ ไม่ใช่โลหะ: ถอยไปที่ PHOTO (จำว่าเหลืองไหม) → เหลือง: ถอยต่อไปราง A แล้วดัน → ดำ: เดินหน้าออกปลายสายพาน

| Device | ความหมาย |
|---|---|
| M0 | Auto กำลังทำงาน |
| M10 | ขั้น ป้อนชิ้นงาน |
| M11 | ขั้น เดินหน้าไปตรวจ IND |
| M12 | ขั้น เดินหน้าไปราง B |
| M13 | ขั้น ดันราง B |
| M14 | ขั้น ถอยไปตรวจ PHOTO |
| M15 | ขั้น ถอยไปราง A |
| M16 | ขั้น ดันราง A |
| M17 | ขั้น ส่งออกปลายสายพาน |
| M20 / M21 | จำว่าเป็นโลหะ / เหลือง |
| M30 / M31 / M32 | กระบอกป้อน / B / A ยืดถึงแล้ว |

```
(* Auto run: X0 start, X2 stop, X12/X112 E-stop แบบ NC *)
|--[X0]--+--[X12]--[X112]--[/X2]------------------------------( M0 )
|--[M0]--+
|--[/M0]-------------------------------------------------------[ZRST M10 M32]

(* เริ่มรอบใหม่: ว่างทุกขั้น, มีชิ้นงาน, กระบอกทุกตัวหดสุด *)
|--[M0]--[= K2M10 K0]--[/X111]--[X103]--[X105]--[X107]---------[SET M10]

(* ป้อน *)
|--[M10]--[X104]-----------------------------------------------[SET M30]
|--[M10]--[M30]--[X103]--------------------------+-------------[RST M30]
|                                                +-------------[RST M10]
|                                                +-------------[SET M11]
|                                                +-------------[RST M20]
|                                                +-------------[RST M21]

(* เดินหน้าไป IND 0.5 s *)
|--[M11]-------------------------------------------------------( T0 K5 )
|--[M11]--[X102]-----------------------------------------------[SET M20]
|--[M11]--[T0]--[M20]------------------------------+-----------[RST M11]
|                                                  +-----------[SET M12]
|--[M11]--[T0]--[/M20]-----------------------------+-----------[RST M11]
|                                                  +-----------[SET M14]

(* ไปราง B 1.2 s แล้วดัน *)
|--[M12]-------------------------------------------------------( T1 K12 )
|--[M12]--[T1]-------------------------------------+-----------[RST M12]
|                                                  +-----------[SET M13]
|--[M13]--[X110]-----------------------------------------------[SET M31]
|--[M13]--[M31]--[X107]----------------------------+-----------[RST M31]
|                                                  +-----------[RST M13]

(* ถอยไป PHOTO 1.0 s *)
|--[M14]-------------------------------------------------------( T2 K10 )
|--[M14]--[X100]-----------------------------------------------[SET M21]
|--[M14]--[T2]--[M21]------------------------------+-----------[RST M14]
|                                                  +-----------[SET M15]
|--[M14]--[T2]--[/M21]-----------------------------+-----------[RST M14]
|                                                  +-----------[SET M17]

(* ไปราง A 0.7 s แล้วดัน *)
|--[M15]-------------------------------------------------------( T3 K7 )
|--[M15]--[T3]-------------------------------------+-----------[RST M15]
|                                                  +-----------[SET M16]
|--[M16]--[X106]-----------------------------------------------[SET M32]
|--[M16]--[M32]--[X105]----------------------------+-----------[RST M32]
|                                                  +-----------[RST M16]

(* ดำ: เดินหน้า 4.5 s ให้ตกปลายสายพาน *)
|--[M17]-------------------------------------------------------( T4 K45 )
|--[M17]--[T4]-------------------------------------------------[RST M17]

(* Output *)
|--[M10]--[/M30]-----------------------------------------------( Y121 )   วาล์วป้อน
|--[M13]--[/M31]-----------------------------------------------( Y123 )   ดันราง B
|--[M16]--[/M32]-----------------------------------------------( Y122 )   ดันราง A
|--[M11]--+----------------------------------------------------( Y120 )   สายพาน
|--[M12]--+
|--[M14]--+
|--[M15]--+
|--[M17]--+
|--[M14]--+----------------------------------------------------( Y124 )   กลับทาง
|--[M15]--+
|--[M0]--------------------------------------------------------( Y0 )     RUN
|--[M10]-------------------------------------------------------( Y1 )     FEEDING
|--[M13]--+----------------------------------------------------( Y2 )     SORTING
|--[M16]--+
|--[/M0]-------------------------------------------------------( Y3 )     STOP
|--[/X12]--+---------------------------------------------------( Y4 )     ALARM
|--[/X112]-+
|--[M0]--[X111]------------------------------------------------( Y5 )     แมกกาซีนว่าง
|--[SM400]-----------------------------------------------------( Y6 )     CONTROL ON
```

`T0–T4` ใน FX5U เป็น Timer 100 ms (K5 = 0.5 s) · ถ้าตั้งเป็น Timer ความละเอียดอื่น ให้คูณค่า K ใหม่
ถ้าเครื่องจริงวิ่งเร็ว/ช้ากว่านี้ ให้ปรับค่า K ตามระยะทาง ÷ ความเร็วสายพานจริง

## 6. ทดสอบโดยไม่มี PLC (Mock FX5U)

`bridge/mock-plc.js` เป็น PLC จำลองแบบ SLMP ที่รันโปรแกรมเดียวกับ Ladder ข้อ 5 ทุกบรรทัด
1. ดับเบิลคลิก **`mock-plc.bat`** (เปิดค้างไว้)
2. ดับเบิลคลิก `start.bat` → เชื่อมต่อ PLC → **PLC จริง (LAN)** → IP `127.0.0.1` Port `5007` → จำลองเครื่องจักร → เชื่อมต่อ
3. กด ▶ เริ่มทำงาน → ชิ้นงาน 9 ชิ้นต้องไปราง A 3, ราง B 3, ปลายสายพาน 3

ใช้เทียบได้ว่าปัญหาอยู่ที่ Ladder ของเรา หรือที่การตั้งค่าเครือข่าย

## 7. แก้ปัญหา

| อาการ / ข้อความ | สาเหตุ / วิธีแก้ |
|---|---|
| "หน้านี้เปิดผ่าน server ที่ไม่มีตัวเชื่อม PLC" | เปิดผ่าน Live Server / python ให้ปิดแล้วเปิด `start.bat` |
| ตรวจสอบ Python: ไม่มี pywin32 | `<python ที่ใช้> -m pip install pywin32` |
| สร้าง MX Component ไม่ได้ | ยังไม่ติดตั้ง MX Component หรือใช้ Python 64-bit กับ MX v4 → ใช้ `py -3.12-32` |
| Open failed 0x01800007 / 0x01808007 | ยังไม่ได้ Start Simulation ใน GX Works3 หรือ Station No. ไม่ได้ตั้งเป็น GX Simulator3 |
| MX Component Open() ไม่ตอบ | Simulator ค้าง ให้ Stop/Start Simulation ใหม่ |
| PLC ปฏิเสธการเชื่อมต่อ (ECONNREFUSED) | ยังไม่ได้เพิ่ม SLMP Connection Module (TCP) ที่ Port นี้ / ยังไม่ Write Parameter + Reset PLC |
| ติดต่อ PLC ไม่ได้ (หมดเวลา) | สายแลน / IP คนละวง / Firewall · ลอง `ping` |
| end code 0xC050/0xC051 | Communication Data Code ต้องเป็น **Binary** |
| end code 0xC059 / เขียนไม่ได้ขณะ RUN | เปิด **Enable All (SLMP)** ที่ Online Change |
| SM400 = 0 | CPU อยู่ STOP → สลับเป็น RUN |
| เซนเซอร์บน PLC จริงไม่เปลี่ยนตามเว็บ | X มีสายจริงถูกเขียนทับทุกสแกน → ใช้ M แทน (ดูข้อ 3) |
| กระบอกดันพลาดชิ้นงาน | ค่า Timer ไม่พอดีตำแหน่ง → ปรับ K ตามข้อ "พฤติกรรมของเครื่องจำลอง" |

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html`, `style.css` | หน้าจอ, แผงควบคุม, ฟอนต์ IBM Plex Sans Thai (อยู่ใน `vendor/fonts`) |
| `app.js` | โมเดล 3D, ลำดับจำลองในตัว, ฟิสิกส์โหมด PLC (Y → การเคลื่อนที่, ตำแหน่ง → X) |
| `io.js` | ตาราง I/O แก้ไขได้ |
| `plc.js` | หน้าต่างเชื่อมต่อ, ส่ง/รับค่า PLC |
| `bridge/server.js` | Web server + ตัวเชื่อม PLC (Node.js ไม่ต้อง npm install) |
| `bridge/slmp.js` | SLMP 3E binary client (อ่านแบบ block, เขียนแบบ random bit) |
| `bridge/mx.js`, `bridge/mx_bridge.py` | ตัวเชื่อม MX Component → GX Simulator3 |
| `bridge/mock-plc.js` | FX5U จำลองสำหรับทดสอบ |
| `bridge/config.json` | ค่าการเชื่อมต่อล่าสุด (สร้างเอง) |
| `start.bat`, `mock-plc.bat` | ตัวเปิดโปรแกรม |

## ขอบเขต
- สัดส่วนประมาณจากภาพถ่าย ไม่ใช่ CAD
- ตาราง I/O ค่าเริ่มต้นและ Ladder ตัวอย่างเป็นแบบฝึก ต้องเทียบกับการเดินสายของเครื่องจริงก่อนใช้
- ตำแหน่งชิ้นงานในโหมด Monitor เป็นค่าประมาณจาก Y เพราะ PLC ไม่รู้ตำแหน่งชิ้นงานจริง
